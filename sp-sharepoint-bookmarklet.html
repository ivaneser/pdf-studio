PDF Studio — SharePoint Bookmarklet

Select PDFs in a modern SharePoint list, then click this bookmark to open them directly in PDF Studio.

📥 Drag me to your bookmarks bar (or right-click it → “Add bookmark”)

Once added, open any SharePoint list, tick the checkboxes next to your PDFs, then click this bookmark. It opens PDF Studio and sends the files automatically.

How it works

  1. Tick checkboxes for the PDFs you want in a modern SharePoint list.
  2. Click the bookmarklet. It downloads your selected files from SharePoint (your login is already valid there).
  3. It opens PDF Studio and sends each file to it — no manual upload.
Note: This runs as JavaScript on the SharePoint page, so it uses your existing login session to download files. It never stores or uploads them anywhere except PDF Studio. For a Document Library with many thousands of files, tick only what you need in one view (SP loads rows lazily).
